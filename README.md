Week 1 — Small Python Data-Processing App
A Python application that loads a raw student-score dataset, cleans the data using reusable functions, and processes numerical values with NumPy.
Key concepts:
Loading data from a CSV file
Cleaning missing, invalid, and duplicate records
Writing reusable Python functions
Calculating descriptive statistics using NumPy
Working with Python scripts and Jupyter notebooks
Technologies: Python, NumPy, pandas, Jupyter Notebook, Google Colab, Git, and GitHub.
